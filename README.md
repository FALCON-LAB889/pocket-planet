# Pocket Planet 🪐

A tiny universe, made by me.

## Features

- Animated solar system with three planets
- Interactive 3D planet previews
- Custom planet names and colours
- Three ring styles with adjustable colours
- Optional moons
- Sparkling stars and shooting stars

## Built with

HTML, CSS, JavaScript and Three.js.

## Current limitations

Customizations reset when the page is refreshed.
An internet connection is needed to load Three.js.

## Next improvements

Planet surface designs, a nebula background and saved settings.
